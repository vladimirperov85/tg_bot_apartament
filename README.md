# Telegram Bot: Расчёт стоимости ремонта квартиры

Учебный проект телеграм-бота на aiogram 3.x. Бот по шагам опрашивает
пользователя (площадь, высота потолков, количество комнат, класс ремонта),
рассчитывает предварительную смету и выводит её с разбивкой по статьям.

## Функциональность

- Пошаговый диалог с пользователем (FSM — машина состояний)
- Ввод: площадь квартиры (10–1000 кв.м), высота потолков (2–5 м),
  количество комнат (1–15), класс ремонта (Эконом / Стандарт / Премиум)
- Валидация ввода с понятными сообщениями об ошибках
- Поддержка запятой как десятичного разделителя (45,5)
- Расчёт сметы: стены, пол, потолок, доставка и уборка
- Надбавка за сложность: +5% за каждую комнату после первой
- Команды: /start — начать расчёт, /cancel — отменить, /help — справка
- Реакция на нетекстовые сообщения (фото, стикеры) в процессе диалога

## Технологии

- Python 3
- aiogram 3.x (асинхронный фреймворк для Telegram Bot API)
- python-dotenv (переменные окружения)

## Установка и запуск

1. Клонируйте репозиторий:

  ```bash
   git clone https://github.com/vladimirperov85/tg_bot_apartament.git
   cd tg_bot_apartament
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
  python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/macOS
   source venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` в корне проекта:

   ```
   BOT_TOKEN=токен_вашего_бота
   ```

   Токен можно получить у [@BotFather](https://t.me/BotFather) в Telegram.

5. Запустите бота:

   ```bash
   python main.py
   ```

## Как считается смета

- Площадь стен ≈ площадь × высота потолков × 1.8
- Стоимость = площадь × (работы + материалы) для стен, пола и потолка
- Расценки зависят от класса ремонта (Эконом / Стандарт / Премиум)
- Доставка и уборка = площадь × 180
- Итог = сумма × коэффициент сложности комнат (+5% за каждую после первой)
